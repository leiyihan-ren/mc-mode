# Quilt · 客户端版本目录

> Quilt 与 Fabric 生态兼容，是另一个轻量级选择。
>
> - **安装包**：[quilt-installer 0.15.1](https://maven.quiltmc.org/repository/release/org/quiltmc/quilt-installer/0.15.1/quilt-installer-0.15.1.jar)（8.3MB，共 34 个历史版本，见 modloaders.json）
> - **支持的游戏版本**：441 个
> - **数据来源**：Quilt 官方 Meta API（meta.quiltmc.org）
> - 目录生成日期：2026-10-23

## 安装方法

```bash
# 1) 下载安装包：https://maven.quiltmc.org/repository/release/org/quiltmc/quilt-installer/0.15.1/quilt-installer-0.15.1.jar
# 2) 安装到游戏目录
java -jar quilt-installer.jar client -mcversion <MC版本> -loader <Loader版本> -dir <游戏目录>
```
